# 개발자 비상근무

## 변수

- Month : 입력된 "월"
- DayOfWeek : 입력된 "시작 요일"
- 평일근무자 list : "평일 비상 근무 순번"
- 주말근무자 list : "주말 비상 근무 순번"
- 근무자 list : 순번 조정을 마친 "전체 근무 순번"
- Day Class List : 전체 "날"에 대한 정보를 저장해둔 클래스 리스트 

## 입출력에 따른 로직

- 월, 시작 요일 입력받기 
  - while() { try()catch() } 로 진행
  - month >= 1 && month <= 12 이여야함
  - 시작 요일은 "월~일"이라는 문자에 해당해야함. 
- 평일근무자, 주말근무자 입력
  - while() {try, catch} 로 진행 
  - 평일 근무자 확인 요소
    - 문자열로 들어옴으로 trim & split(",")
    - list 내에서 겹치면 안되므로 list.contain()에서 거짓이 나와야함
    - name.length <= 5
  - 전체 확인하고 난 다음에는 평일 근무자.size <= 35 && size >= 5 여야함
  - 주말 근무자 확인 요소
    - 평일 근무자에 포함되어있는지 확인해야함
- Day Class List를 돌면서 
  - isholiday 가 아니라면 평일 근무자 순번으로 확인
    - 이전 순서명단이름과 동일할 시에 평일 근무자가 자신의 뒤에 근무자와 순서를 바꿔야한다. 
  - isHoliday 라면 주말 근무자 순번으로 확인
    - 이전 순서명단이름과 동일할 시에 평일 근무자가 자신의 뒤에 근무자와 순서를 바꿔야한다. 
- 전체 순서 명단자를 완성했으면 날짜를 다시 돌면서
  - 일반적으로는 "${월}월 ${일}일 ${명단}"
  - 만약 isHoliday인데 !isWeekend일 경우 "${월}월 ${일}일(휴일) ${명단}" 로 출력한다.
