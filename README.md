# 미션 - 크리스마스 프로모션

## 입력과 출력 플로우에 따른 검사 요소

1. "안녕하세요! 우테코 식당 12월 이벤트 플래너입니다." 출력
2. 날짜 입력
   1. "12월 중 식당 예상 방문 날짜는 언제인가요? (숫자만 입력해 주세요!)" 출력
   2. 날짜 입력 받기
      - checklist
      - [x] 1 ~ 31 사이의 숫자인지 확인 -> "[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
---
3. 메뉴 입력
   1. "주문하실 메뉴를 메뉴와 개수를 알려 주세요. (e.g. 해산물파스타-2,레드와인-1,초코케이크-1)" 출력
   2. 메뉴 입력 받기
     - ","로 분리 -> "-"로 분리
      - checklist
      - [x] 주문서가 포맷에 맞는지 확인 -> "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
      - [x] 메뉴가 메뉴판에 존재하는지 확인 -> "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
      - [x] 동일 메뉴가 이미 입력되었는지 확인 -> "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
      - [x] 메뉴 주문 갯수가 1개 이상인지 확인 -> "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
      - [x] 총 주문 갯수가 20개 이하인지 확인 -> "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
      - [x] 메뉴가 음료로만 이루어있지 않도록 확인 -> "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요." 출력 후 재입력 받도록
4. "12월 ${date}일에 우테코 식당에서 받을 이벤트 혜택 미리 보기!" 출력
5. println() 출력
6. 주문 메뉴 리스트 출력 
   1. "<주문 메뉴>" 출력
   2. 메뉴 리스트 출력
      - [ ] 형식 : "${메뉴명} ${갯수}개"ex) 타파스 1개
7. println() 출력
8. 할인 전 총주문금액 출력
   1. "<할인 전 총주문 금액>" 출력
   2. 메뉴 리스트의 갯수와 금액을 곱하여 연산 후 출력
      - [ ] 형식 : 3자리 수마다 ,로 나누어 출력 ex) 142,000원
9. println() 출력
10. 증정메뉴 출력(샴페인 여부)
    1. "<증정 메뉴>" 출력
    2. 할인 전 총주문금액 >= 120,000인지 확인
    3. 맞을 경우 "샴페인 1개" 출력
       - 아닐 경우 "없음" 출력
11. println()
12. 혜택내역 출력
    1. "<혜택 내역>" 출력
    2. 크리스마스 디데이 여부 확인
       - [ ] 날짜가 1~25 이면 1000+100*(날짜-1) 만큼 할인
       - [ ] 형식 : "크리스마스 디데이 할인: -${금액}원" ex) 크리스마스 디데이 할인: -1,200원
    3. 평일 할인 여부 확인
       - [ ] 요일이 평일이면 디저트 1개당 2,023원 할인
       - [ ] 형식 : "평일 할인: -${금액}원" ex) 평일 할인: -4,046원
    4. 주말 할인 여부 확인
       - [ ] 요일이 주말이면 메인 1개당 2,023원 할인
       - [ ] 형식 : "주말 할인: -${금액}원" ex) 주말 할인: -4,046원
    5. 특별 할인 여부 확인
       - [ ] 해당 날짜가 별표표시된 날짜이면 1000원만큼 할인
       - [ ] 형식 : "특별 할인: -1,000원" 
    6. 증정 이벤트 확인
       - [ ] 할인 전 총주문금액 >= 120,000인지 확인
       - [ ] 형식 : "증정 이벤트: -25,000원"
    - 없을 시에는 "없음" 출력
13. println()
14. 총 헤택 금액 출력
    1. "<총혜택 금액>" 출력
    2. 12번에서 혜택 받았던 금액을 모두 합하여 출력
        - [ ] 형식 : "-${총금액}원" 
15. println()
16. 할인 후 예상금액 출력
    1. "<할인 후 예상 결제 금액>" 출력
    - 샴페인 금액 제외 후 출력
    - [ ] 형식 : "${할인전금액-샴페인금액제외혜택금액}원"
17. println()
18. 12월 이벤트 뱃지 출력
    1. "<12월 이벤트 배지>" 출력
    2. 총 혜택 금액이 >= 20000 -> "산타" 출력
    3. 총 혜택 금액이 >= 10000 -> "트리" 출력
    4. 총 혜택 금액이 >= 5000 -> "별" 출력
    5. else -> "없음" 출력
